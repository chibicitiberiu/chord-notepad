==================
Keyboard Shortcuts
==================

.. only:: desktop

   Keyboard shortcuts let you work faster. This page lists all available shortcuts
   organized by category. Most menu items also show their shortcut on the right, so
   you can pick them up as you go. On macOS, **Ctrl** here is **Cmd**.

.. only:: android

   The keyboard shortcuts on this page work when a hardware keyboard is
   attached to your phone or tablet (over Bluetooth or USB, or a tablet's
   keyboard cover), and on a Chromebook, where a mouse or trackpad also does
   everything a tap does. You never need them: everything they do is also on the
   screen, in the ☰ drawer, the Edit ribbon or the player. The touch gestures
   are listed too, where they apply.


File Operations
===============

.. only:: desktop

   .. list-table::
      :header-rows: 1
      :widths: 30 70

      * - Shortcut
        - Action
      * - Ctrl+N
        - New file
      * - Ctrl+O
        - Open file
      * - Ctrl+S
        - Save file
      * - Ctrl+Shift+S
        - Save As (save with new name)
      * - Ctrl+Q
        - Quit

.. only:: android

   .. list-table::
      :header-rows: 1
      :widths: 30 70

      * - Shortcut
        - Action
      * - Ctrl+N
        - New song
      * - Ctrl+O
        - Open a song
      * - Ctrl+S
        - Save
      * - Ctrl+Shift+S
        - Save as (under a new name or in a new place)

   There is no shortcut to quit. Press Back on the main screen to leave the
   app; if the song has unsaved changes, it asks whether to save them first.


Edit Operations
===============

.. only:: desktop

   .. list-table::
      :header-rows: 1
      :widths: 30 70

      * - Shortcut
        - Action
      * - Ctrl+Z
        - Undo
      * - Ctrl+Y or Ctrl+Shift+Z
        - Redo
      * - Ctrl+X
        - Cut selected text
      * - Ctrl+C
        - Copy selected text
      * - Ctrl+V
        - Paste from clipboard
      * - Ctrl+A
        - Select all text
      * - Ctrl+L
        - Select the line (again: one more line)
      * - Ctrl+D
        - Duplicate the line, or the selection
      * - Ctrl+Shift+K
        - Delete the line, or the selected lines
      * - Ctrl+Shift+Up / Ctrl+Shift+Down
        - Move the line, or the selected lines, up or down
      * - Ctrl+/
        - Comment or uncomment the line or the selected lines (``//``)
      * - Tab / Shift+Tab
        - Indent / unindent the selected lines (Tab within one line types a tab;
          Shift+Tab without a selection unindents the cursor's line)
      * - Insert
        - Overwrite mode on or off (OVR in the status bar)
      * - Ctrl+Enter, Shift+Enter
        - A new line, like Enter

   Moving the cursor:

   .. list-table::
      :header-rows: 1
      :widths: 30 70

      * - Shortcut
        - Action
      * - Home
        - The line's first character that isn't a space; again, the very
          start of the line
      * - End
        - The end of the line; with text selected, the end of the selection
      * - Ctrl+Left / Ctrl+Right
        - A word left or right
      * - Ctrl+Home / Ctrl+End
        - The start or end of the song
      * - Page Up / Page Down
        - A screenful up or down
      * - Ctrl+Up / Ctrl+Down
        - Scroll a line without moving the cursor
      * - Ctrl+Backspace / Ctrl+Delete
        - Delete the word before or after the cursor

   Hold **Shift** with any of the moves to select as you go.

.. only:: android

   These work in the Edit tab, while the cursor is in the text.

   .. list-table::
      :header-rows: 1
      :widths: 30 70

      * - Shortcut
        - Action
      * - Ctrl+Z
        - Undo
      * - Ctrl+Y or Ctrl+Shift+Z
        - Redo
      * - Ctrl+X
        - Cut selected text
      * - Ctrl+C
        - Copy selected text
      * - Ctrl+V
        - Paste from clipboard
      * - Ctrl+A
        - Select all text

   Without a keyboard, Undo and Redo are in the Edit ribbon, and cut, copy,
   paste and select all are in the menu that appears when you select text.


.. only:: desktop

   Find and Replace
   ================

   .. list-table::
      :header-rows: 1
      :widths: 30 70

      * - Shortcut
        - Action
      * - Ctrl+F
        - Find (the bar under the text)
      * - Ctrl+H
        - Find and replace
      * - Enter / Shift+Enter
        - In the find field: next / previous match
      * - F3 / Shift+F3
        - Next / previous match, also with the bar closed
      * - Escape
        - Close the bar, back to the text
      * - Ctrl+G
        - Go to a line

   See :ref:`find-and-replace` for the details.


View / Zoom
===========

.. only:: desktop

   .. list-table::
      :header-rows: 1
      :widths: 30 70

      * - Shortcut
        - Action
      * - Ctrl+Plus
        - Larger text
      * - Ctrl+=
        - Larger text (same as above)
      * - Ctrl+Minus
        - Smaller text
      * - Ctrl+0
        - Reset text size to default (11pt)
      * - Ctrl+Mouse Wheel
        - Zoom the text in/out
      * - Ctrl+Alt+Plus / Ctrl+Alt+Minus / Ctrl+Alt+0
        - Zoom the whole window in, out, back to 100%
      * - F11
        - Full screen
      * - Ctrl+1 / Ctrl+2
        - Edit / Play workspace
      * - Ctrl+Shift+D / Ctrl+Shift+I
        - Directives sidebar / Chord identifier (open, or close if already open)
      * - F9
        - Show or hide the chord sheet under the text (Edit)
      * - Alt+1 to Alt+4
        - Chord sheet view: Piano roll, Staff, Fret cards, Tab
      * - Ctrl+Shift+L
        - Dark theme on or off
      * - Alt, F10, Alt+F / E / V / P / T / H
        - Show the menu bar, open its first menu, open that menu

.. only:: android

   .. list-table::
      :header-rows: 1
      :widths: 30 70

      * - Shortcut
        - Action
      * - Ctrl+Plus
        - Increase font size
      * - Ctrl+=
        - Increase font size (same as above)
      * - Ctrl+Minus
        - Decrease font size
      * - Ctrl+0
        - Reset font size to default (11pt)
      * - Pinch
        - Zoom in/out: spread two fingers on the text to make it bigger, pinch them together to make it smaller (in both tabs)

   The size you pick is remembered, and it's the same setting as the font size
   in **☰ → Settings → General**.


Playback
========

.. only:: desktop

   .. list-table::
      :header-rows: 1
      :widths: 30 70

      * - Shortcut
        - Action
      * - F5
        - Play, pause, resume (from the playhead)
      * - Shift+F5
        - Stop and rewind
      * - Click Play button
        - Play from the playhead
      * - Shift+Click Play
        - Play from the text cursor
      * - Click valid chord
        - Play that chord and move the playhead there
      * - Shift+Click valid chord
        - Play that chord rolled, one note at a time (in the text or the chord sheet)
      * - Ctrl+M
        - Metronome on or off
      * - Ctrl+] / Ctrl+[ / Ctrl+Backslash
        - Speed up 5% / down 5% / back to 100%
      * - Alt+Down
        - Open the picker of the song value or directive you're on (Edit → Change value…)
      * - Ctrl+T
        - Transpose
      * - Ctrl+,
        - Settings

.. only:: android

   Playback has no keyboard shortcuts. In the Play tab:

   .. list-table::
      :header-rows: 1
      :widths: 30 70

      * - Gesture
        - Action
      * - Tap ▶ / ❚❚
        - Play from the playhead, pause, resume
      * - Tap ⏮
        - Stop and put the playhead back on the first chord
      * - Tap a chord
        - Move the playhead there and play that chord (while a song plays,
          jump playback there)
      * - Tap elsewhere in the text
        - Move the playhead to the nearest chord (does nothing while a song
          plays)
      * - Drag the playhead marker
        - Move the playhead chord by chord


Text Editor
===========

.. only:: desktop

   .. list-table::
      :header-rows: 1
      :widths: 30 70

      * - Shortcut
        - Action
      * - Enter / Return
        - New line
      * - NumPad Enter
        - New line (same as Enter)
      * - Tab
        - Insert tab character
      * - Backspace
        - Delete character before cursor
      * - Delete
        - Delete character after cursor

.. only:: android

   In the Edit tab, the usual editing keys work on an attached keyboard:
   Enter for a new line, Backspace and Delete, the arrow keys, and Shift with
   the arrow keys to select.
