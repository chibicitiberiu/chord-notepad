==================
Keyboard Shortcuts
==================

.. only:: desktop

   Keyboard shortcuts let you work faster. This page lists all available shortcuts
   organized by category. Most menu items also show their shortcut on the right, so
   you can pick them up as you go.

.. only:: android

   Keyboard shortcuts only work on Android when a hardware keyboard is
   attached. Every action is also in the ☰ drawer or the Edit ribbon, and the text and
   the player are touch-driven (see each section below).


File Operations
===============

.. only:: desktop

   .. list-table::
      :header-rows: 1
      :widths: 30 70

      * - Shortcut
        - Action
      * - Ctrl+N
        - New file
      * - Ctrl+O
        - Open file
      * - Ctrl+S
        - Save file
      * - Ctrl+Shift+S
        - Save As (save with new name)
      * - Ctrl+Q
        - Exit application

.. only:: android

   With a keyboard attached: Ctrl+N (new), Ctrl+O (open), Ctrl+S (save),
   Ctrl+Shift+S (save as).


Edit Operations
===============

.. only:: desktop

   .. list-table::
      :header-rows: 1
      :widths: 30 70

      * - Shortcut
        - Action
      * - Ctrl+Z
        - Undo
      * - Ctrl+Y
        - Redo
      * - Ctrl+X
        - Cut selected text
      * - Ctrl+C
        - Copy selected text
      * - Ctrl+V
        - Paste from clipboard
      * - Ctrl+A
        - Select all text

.. only:: android

   With a keyboard attached: Ctrl+Z (undo), Ctrl+Y (redo), Ctrl+A (select all).


View / Zoom
===========

.. only:: desktop

   .. list-table::
      :header-rows: 1
      :widths: 30 70

      * - Shortcut
        - Action
      * - Ctrl+Plus
        - Increase font size
      * - Ctrl+=
        - Increase font size (same as above)
      * - Ctrl+Minus
        - Decrease font size
      * - Ctrl+0
        - Reset font size to default (11pt)
      * - Ctrl+Mouse Wheel
        - Zoom in/out

.. only:: android

   With a keyboard attached: Ctrl+Plus and Ctrl+Minus change the font size and
   Ctrl+0 resets it. You can also pinch the editor.


Playback
========

.. only:: desktop

   .. list-table::
      :header-rows: 1
      :widths: 30 70

      * - Shortcut
        - Action
      * - Click Play Button
        - Play from beginning
      * - Shift+Click Play
        - Play from cursor position
      * - Click valid chord
        - Play that chord

.. only:: android

   In the Play tab, tap ▶/⏸ in the player to play or pause, and ⏮ to go back to
   the first chord. Tap a chord to move the playhead there and hear it;
   playback starts from the playhead.


Text Editor
===========

.. only:: desktop

   .. list-table::
      :header-rows: 1
      :widths: 30 70

      * - Shortcut
        - Action
      * - Enter / Return
        - New line
      * - NumPad Enter
        - New line (same as Enter)
      * - Tab
        - Insert tab character
      * - Backspace
        - Delete character before cursor
      * - Delete
        - Delete character after cursor

.. only:: android

   The usual editing keys work on an attached keyboard.

Quick Reference Card
====================

.. only:: desktop

   This can be printed as a reference card.

   ::

      CHORD NOTEPAD - KEYBOARD SHORTCUTS

      FILE                    EDIT
      ----                    ----
      Ctrl+N    New           Ctrl+Z    Undo
      Ctrl+O    Open          Ctrl+Y    Redo
      Ctrl+S    Save          Ctrl+X    Cut
      Ctrl+Shift+S  Save As   Ctrl+C    Copy
      Ctrl+Q    Exit          Ctrl+V    Paste
                              Ctrl+A    Select All

      VIEW                    PLAYBACK
      ----                    --------
      Ctrl++    Zoom In       Click ▶   Play
      Ctrl+-    Zoom Out      Shift+▶   Play from cursor
      Ctrl+0    Reset Zoom    Click ⏹   Stop
      Ctrl+Wheel  Zoom        Click chord  Play chord

.. only:: android

   The reference card above is for the desktop app.
