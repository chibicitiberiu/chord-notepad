==================
Keyboard Shortcuts
==================

.. only:: desktop

   Keyboard shortcuts let you work faster. This page lists all available shortcuts
   organized by category. Most menu items also show their shortcut on the right, so
   you can pick them up as you go.

.. only:: android

   The keyboard shortcuts on this page work when a hardware keyboard is
   attached to your phone or tablet (over Bluetooth or USB, or a tablet's
   keyboard cover). You never need them: everything they do is also on the
   screen, in the ☰ drawer, the Edit ribbon or the player. The touch gestures
   are listed too, where they apply.


File Operations
===============

.. only:: desktop

   .. list-table::
      :header-rows: 1
      :widths: 30 70

      * - Shortcut
        - Action
      * - Ctrl+N
        - New file
      * - Ctrl+O
        - Open file
      * - Ctrl+S
        - Save file
      * - Ctrl+Shift+S
        - Save As (save with new name)
      * - Ctrl+Q
        - Exit application

.. only:: android

   .. list-table::
      :header-rows: 1
      :widths: 30 70

      * - Shortcut
        - Action
      * - Ctrl+N
        - New song
      * - Ctrl+O
        - Open a song
      * - Ctrl+S
        - Save
      * - Ctrl+Shift+S
        - Save as (under a new name or in a new place)

   There is no shortcut to quit. Press Back on the main screen to leave the
   app; if the song has unsaved changes, it asks whether to save them first.


Edit Operations
===============

.. only:: desktop

   .. list-table::
      :header-rows: 1
      :widths: 30 70

      * - Shortcut
        - Action
      * - Ctrl+Z
        - Undo
      * - Ctrl+Y (Windows), Ctrl+Shift+Z (Linux)
        - Redo
      * - Ctrl+X
        - Cut selected text
      * - Ctrl+C
        - Copy selected text
      * - Ctrl+V
        - Paste from clipboard
      * - Ctrl+A
        - Select all text

.. only:: android

   These work in the Edit tab, while the cursor is in the text.

   .. list-table::
      :header-rows: 1
      :widths: 30 70

      * - Shortcut
        - Action
      * - Ctrl+Z
        - Undo
      * - Ctrl+Y or Ctrl+Shift+Z
        - Redo
      * - Ctrl+X
        - Cut selected text
      * - Ctrl+C
        - Copy selected text
      * - Ctrl+V
        - Paste from clipboard
      * - Ctrl+A
        - Select all text

   Without a keyboard, Undo and Redo are in the Edit ribbon, and cut, copy,
   paste and select all are in the menu that appears when you select text.


View / Zoom
===========

.. only:: desktop

   .. list-table::
      :header-rows: 1
      :widths: 30 70

      * - Shortcut
        - Action
      * - Ctrl+Plus
        - Increase font size
      * - Ctrl+=
        - Increase font size (same as above)
      * - Ctrl+Minus
        - Decrease font size
      * - Ctrl+0
        - Reset font size to default (11pt)
      * - Ctrl+Mouse Wheel
        - Zoom in/out

.. only:: android

   .. list-table::
      :header-rows: 1
      :widths: 30 70

      * - Shortcut
        - Action
      * - Ctrl+Plus
        - Increase font size
      * - Ctrl+=
        - Increase font size (same as above)
      * - Ctrl+Minus
        - Decrease font size
      * - Ctrl+0
        - Reset font size to default (11pt)
      * - Pinch
        - Zoom in/out: spread two fingers on the text to make it bigger, pinch them together to make it smaller (in both tabs)

   The size you pick is remembered, and it's the same setting as the font size
   in **☰ → Settings → General**.


Playback
========

.. only:: desktop

   .. list-table::
      :header-rows: 1
      :widths: 30 70

      * - Shortcut
        - Action
      * - Click Play Button
        - Play from beginning
      * - Shift+Click Play
        - Play from cursor position
      * - Click valid chord
        - Play that chord

.. only:: android

   Playback has no keyboard shortcuts. In the Play tab:

   .. list-table::
      :header-rows: 1
      :widths: 30 70

      * - Gesture
        - Action
      * - Tap ▶ / ❚❚
        - Play from the playhead, pause, resume
      * - Tap ⏮
        - Stop and put the playhead back on the first chord
      * - Tap a chord
        - Move the playhead there and play that chord (while a song plays,
          jump playback there)
      * - Tap elsewhere in the text
        - Move the playhead to the nearest chord
      * - Drag the playhead marker
        - Move the playhead chord by chord


Text Editor
===========

.. only:: desktop

   .. list-table::
      :header-rows: 1
      :widths: 30 70

      * - Shortcut
        - Action
      * - Enter / Return
        - New line
      * - NumPad Enter
        - New line (same as Enter)
      * - Tab
        - Insert tab character
      * - Backspace
        - Delete character before cursor
      * - Delete
        - Delete character after cursor

.. only:: android

   In the Edit tab, the usual editing keys work on an attached keyboard:
   Enter for a new line, Backspace and Delete, the arrow keys, and Shift with
   the arrow keys to select.

Quick Reference Card
====================

.. only:: desktop

   This can be printed as a reference card.

   ::

      CHORD NOTEPAD - KEYBOARD SHORTCUTS

      FILE                    EDIT
      ----                    ----
      Ctrl+N    New           Ctrl+Z    Undo
      Ctrl+O    Open          Ctrl+Y    Redo (Windows)
      Ctrl+S    Save          Ctrl+X    Cut
      Ctrl+Shift+S  Save As   Ctrl+C    Copy
      Ctrl+Q    Exit          Ctrl+V    Paste
                              Ctrl+A    Select All
                              Ctrl+Shift+Z  Redo (Linux)

      VIEW                    PLAYBACK
      ----                    --------
      Ctrl++    Zoom In       Click ▶   Play
      Ctrl+-    Zoom Out      Shift+▶   Play from cursor
      Ctrl+0    Reset Zoom    Click ⏹   Stop
