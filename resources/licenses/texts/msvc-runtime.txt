Microsoft Visual C++ Runtime

The Windows build of Chord Notepad includes runtime files of the Microsoft
Visual C++ Redistributable and the Universal C Runtime (vcruntime140.dll,
vcruntime140_1.dll and, where present, msvcp140.dll, ucrtbase.dll and the
api-ms-win-*.dll forwarders). Python for Windows is compiled against them.
